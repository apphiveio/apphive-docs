# Get the Firebase Storage URL

!!! note
    Recovered from the previous Apphive documentation. Some screenshots could not be recovered.

1.- In the Firebase console, select **Storage** and click on **Start**.

2.- Click on **Next**, verify that the location is `nam5 (us-central)` and click on **Done**.

3.- Copy the bucket URL shown at the top of the Files tab (for example `your-project.appspot.com`). Keep it, as it will be requested to generate your compilation.
