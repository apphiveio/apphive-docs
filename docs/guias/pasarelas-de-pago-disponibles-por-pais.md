# Pasarelas de pago disponibles por país

No todas las pasarelas de pago operan en todos los países. Por ejemplo, **Stripe no está disponible en Bolivia**: ahí las opciones de esta lista son PayPal y Airtm. Usa las tablas para elegir la pasarela que funciona en el país donde está registrado tu negocio.

!!! warning
    La cobertura de cada pasarela cambia con el tiempo. Antes de integrar una, confirma en su sitio oficial que opera en tu país.

## Pasarelas por país

| País | Pasarelas |
| --- | --- |
| México | Stripe, Conekta, OpenPay, Mercado Pago, PayU, 2Checkout, PayPal |
| Colombia | PayU, ePayco, Mercado Pago, Wompi, PayPal |
| Ecuador | Pagomedios, PayPal |
| Perú | Mercado Pago, PayU, Culqi, PayPal |
| España | Stripe, Mercado Pago, PayPal |
| Chile | Transbank, PagoFácil, Kushki, Payku, PayPal |
| Argentina | Mercado Pago, PayPal |
| Estados Unidos | Stripe, PayPal |
| Venezuela | Airtm, PayPal |
| Bolivia | Airtm, PayPal |
| El Salvador | Wompi, Pagadito, PayPal |
| Panamá | PagueloFacil, PayPal |

La segunda tabla incluye más opciones por país (por ejemplo, Kushki también opera en Ecuador, Perú y México).

## Cómo conectarlas a tu app

- **Stripe** tiene funciones propias en el editor: consulta las [funciones de Stripe](../reference/funciones/stripe/README.md).
- Las demás pasarelas se conectan a través de su API, igual que cualquier otro servicio externo. Consulta [integración con APIs](https://apphive.io/es/funciones/apis) y [pagos en Apphive](https://apphive.io/es/funciones/payments).
