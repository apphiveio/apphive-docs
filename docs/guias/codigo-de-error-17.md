# Código de error: 17

El código de error 17 lo provoca la **imagen que tienes cargada como icono de tu app**. Cambia el icono por otra imagen y vuelve a compilar.

## Cómo resolverlo

1. Cambia la imagen del icono de tu app. En este video se muestra dónde cambiarla: [ver video](https://www.loom.com/share/774279168d6f49b1b5d838385ce6fbb5).
2. Vuelve a compilar.
3. Si vuelve a fallar, prueba con otra imagen, hasta un máximo de **3 imágenes distintas**.

Si la compilación termina con éxito, el problema quedó resuelto.

## Si el error continúa

Si después de cambiar 3 veces el icono el error persiste, escribe a soporte desde el chat del editor (abajo a la derecha) con esta información:

1. Tu correo electrónico de contacto.
2. La URL de la app con error.
3. El código de error que recibiste por correo (incluye una captura del correo).
4. Lo que ya intentaste antes de escribir.
