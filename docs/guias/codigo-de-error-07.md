# Código de error 07 (compilación iOS)

El código de error 07 aparece cuando la **API Key** que generaste la última vez para compilar para iOS ya no es válida. El sistema te pedirá que agregues una API Key de nuevo.

!!! warning
    Cuando el sistema te pida la API Key, **no ingreses la anterior**: ya es inválida. Crea una nueva y agrégala.

## Solución

1. Genera una nueva API Key en tu cuenta de desarrollador de Apple.
2. Agrégala cuando el sistema te la pida y manda a compilar de nuevo.
3. Si la compilación se procesa con éxito, el problema quedó resuelto.

## Si vuelve a fallar

Escribe al chat de soporte con esta información:

1. El correo electrónico de tu cuenta.
2. La URL de la aplicación con error.
3. El código de error que recibiste por correo (incluye una captura del correo).
4. Las acciones que ya realizaste antes de escribir.
