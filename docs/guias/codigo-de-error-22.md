# Código de error 22 en la compilación

El **código de error 22** aparece cuando la **URL de la base de datos (DB URL) de Firebase** que diste al compilar ya no es válida. Para resolverlo, vuelve a compilar: el sistema te pedirá una nueva DB URL.

## Pasos

1. **Vuelve a compilar y agrega una nueva DB URL.** Es la URL de la Realtime Database de tu proyecto de Firebase. Si la compilación sale bien, el problema quedó resuelto.
2. **Contacta a soporte** si la compilación vuelve a fallar. Escribe por el chat de soporte e incluye:
    1. Tu correo electrónico de contacto.
    2. La URL de la aplicación con error.
    3. El código de error que te llegó por correo (con una captura del correo).
    4. Lo que ya intentaste antes de escribir.
