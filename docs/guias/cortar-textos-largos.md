# Cortar textos largos

Si un texto es demasiado largo para mostrarlo completo en tu app y sólo quieres mostrar una parte, recórtalo con la función **Global Formater**, que permite hacer un corte de caracteres. Para textos, el tipo de origen es **string** y el de salida es **slice**.

En este video se explica paso a paso: [ver el video](https://sharing.clickup.com/clip/p/t8583554/7c4c125b-f6cd-485b-8722-cfbb981f751f/screen-recording-2023-11-16-12%3A23.webm)

Consulta la referencia de la función en [Global Formater](../reference/funciones/logic-e/global-formater/README.md).
