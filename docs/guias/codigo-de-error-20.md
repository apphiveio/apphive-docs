# Código de error: 20

El código de error 20 aparece cuando el **Compilation ID** que proporcionaste en la compilación no es válido. Para resolverlo, vuelve a compilar: el sistema te pedirá un nuevo Compilation ID.

## Pasos

1. **Manda a compilar una vez más y agrega un nuevo Compilation ID.** Si la compilación es exitosa, el problema está resuelto. Si vuelve a dar error, sigue con el paso 2.
2. **Escribe al soporte** desde el chat del editor (la burbuja azul) e incluye:
    1. Tu correo electrónico de contacto.
    2. La URL de la app con el error.
    3. El código de error que te llegó por correo (incluye una captura del correo).
    4. Las acciones que ya realizaste antes de escribir (por ejemplo, si seguiste alguna guía en especial).

!!! warning
    Si tu app ya está publicada en Google Play, las actualizaciones deben llevar exactamente el mismo Compilation ID que la primera versión. Consulta [Tu Android App Bundle está firmado con la clave incorrecta](tu-android-app-bundle-esta-firmado-con-la-clave-incorrecta.md).
