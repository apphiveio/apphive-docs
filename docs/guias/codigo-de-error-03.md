# Código de error 03 en la compilación

Si tu compilación falla con el **código de error 03**, primero vuelve a compilar. Si falla otra vez, revisa la **facturación de Google Cloud** de tu proyecto de Firebase: un pago pendiente es la causa más común.

## Pasos

1. **Vuelve a compilar.** Si la segunda compilación sale bien, el problema quedó resuelto. Si vuelve a fallar, sigue con el paso 2.
2. **Revisa la facturación de tu proyecto.** Entra a tu cuenta de facturación en Google Cloud Console y verifica que no tengas ningún aviso de pago pendiente.

    Video con las indicaciones: [cómo revisar la facturación](https://www.loom.com/share/d0c4217217b3495aae0cc4af0d3cd076)

    Si tu proyecto de Firebase tiene una deuda pendiente, págala, ya sea cambiando el método de pago o agregando fondos a la cuenta actual. Después vuelve a compilar.

3. **Contacta a soporte** si no tienes pagos pendientes y el error continúa. Escribe por el chat de soporte e incluye:
    1. Tu correo electrónico de contacto.
    2. La URL de la aplicación con error.
    3. El código de error que te llegó por correo (con una captura del correo).
    4. Lo que ya intentaste antes de escribir.
