# Código de error: 01

Si tu compilación terminó con el código de error 01, primero vuelve a mandarla a compilar: muchas veces la segunda compilación sale bien. Si vuelve a fallar, contacta al soporte.

## Pasos

1. **Manda a compilar una vez más.** Si la compilación es exitosa, el problema está resuelto. Si vuelve a dar error, sigue con el paso 2.
2. **Escribe al soporte** desde el chat del editor (la burbuja azul) e incluye:
    1. Tu correo electrónico de contacto.
    2. La URL de la app con el error.
    3. El código de error que te llegó por correo (incluye una captura del correo).
    4. Las acciones que ya realizaste antes de escribir (por ejemplo, si seguiste alguna guía en especial).

Consulta también [Código de error: 20](codigo-de-error-20.md).
