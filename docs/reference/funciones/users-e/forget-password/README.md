# Forget Password

La función Forget Password permite a los usuarios recuperar para después cambiar su contraseña enviando un correo electrónico al correo electrónico del usuario, esta función es importante para que los usuarios protejan su cuenta.

![](../../../../gitbook/assets/image%20%28347%29.png)

[Información general](https://docs.apphive.io/reference/funciones/informacion-general-de-las-funciones)





=== "Callbacks"

    ## Email not sent

    Se activa cuando el el correo no se envió exitosamente al correo

    ## Email not found

    Se activa cuando el correo que se integró no es valido y por lo que no se encuentra y no se puede enviar el mensaje

    ## Email sent

    Se activa cuando el correo se envió exitosamente

=== "Entry vars"

    ## Email



    ![](../../../../gitbook/assets/image%20%28365%29.png)

    Permite ingresar el correo electrónico a cual se le enviará un correo electrónico con instrucciones para recuperar su contraseña
