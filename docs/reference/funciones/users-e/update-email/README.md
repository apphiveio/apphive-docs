# Update email

![](../../../../gitbook/assets/image%20%28611%29.png)

La función Update email permite actualizar el correo electrónico del usuario que actualmente se encuentra con la sesión iniciada

[Información general](https://docs.apphive.io/reference/funciones/informacion-general-de-las-funciones) 



=== "Callbacks"

    ## Error

    Se activa cuando ocurre un error durante el proceso de actualización del correo

    ## Success

    Se activa cuando el proceso de actualización de información concluye de forma exitosa

=== "Entry Vars"

    ## email

    ![](../../../../gitbook/assets/image%20%28581%29.png)

    Permite ingresar para actualizar el nuevo correo electrónico del usuario con la sesión iniciada
