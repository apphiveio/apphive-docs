# Stop set interval

![](../../../../gitbook/assets/image%20%28683%29.png)

La función Stop set interval permite detener la secuencia de la función **Set interval**

[Información general](https://docs.apphive.io/reference/funciones/informacion-general-de-las-funciones)



=== "Callbacks"

    ## Done

    Se activa cuando se detuvo el proceso del Set interval correspondiente al id agregado en la función de forma exitosa

    ## Error

    Se activa cuando ocurre un error durante el proceso de detención de la función Set interval

=== "Entry Vars"

    ## interval id

    ![](../../../../gitbook/assets/image%20%28653%29.png)

    Se agrega el id que genera la función **Set interval** para poder detener su proceso, si se tiene mas de un proceso de **Set interva**l se debe agregar una función **Stop set interval** por cada función.
