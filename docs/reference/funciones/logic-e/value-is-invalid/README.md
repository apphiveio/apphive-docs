# Value is invalid

![](../../../../gitbook/assets/image%20%28446%29.png)

La función Value in invalid permite discriminar los valores nulos, indicado como validos los valores diferentes a nulo o vacío

[Información general](https://docs.apphive.io/reference/funciones/informacion-general-de-las-funciones)



=== "Callbacks"

    ## Is a valid value

    Se activa cuando el valor de la variable de entrada es diferente a nulo

    ## Is an invalid value

    Se activa cuando el valor de la variable de entrada es igual a nulo

=== "Entry Vars"

    ## Variable to validate

    ![](../../../../gitbook/assets/image%20%28466%29.png)

    Permite validar los datos de entrada, discriminando variables con valores nulos
