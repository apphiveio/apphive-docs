# debounce

![](../../../../gitbook/assets/image%20%28444%29.png)

La función debunce permite establecer un tiempo en milisegundos antes de hacer ejecución de las funciones, generalmente se utiliza para crear un tiempo de espera antes de ejecutar una lógica de funciones

[Información general](https://docs.apphive.io/reference/funciones/informacion-general-de-las-funciones)



=== "Callbacks"

    ## Activated 

    Se activa cundo el tiempo establecido en milisegundo se completa de forma exitosa

    ## onError

    Se activa cuando ocurre algún error durante el proceso de transición

=== "Entry Vars"

    ## Time miliseconds

    ![](../../../../gitbook/assets/image%20%28462%29.png)

    Se ingresa un valor numérico el cual será representado en milisegundos

    !!! info

        1 segundo = 1000 milisegundos

        1 milisegundo = 0.001 segundos
