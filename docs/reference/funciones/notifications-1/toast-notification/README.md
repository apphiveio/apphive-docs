# Toast notification

![](../../../../gitbook/assets/image%20%28483%29.png)

La función Toast notification permite mandar una notificación discreta en el dispositivo con un tiempo limitado de vida

[Información general](https://docs.apphive.io/reference/funciones/informacion-general-de-las-funciones)



=== "Entry Vars"

    ## Mesage

    ![](../../../../gitbook/assets/image%20%28496%29.png)

    Permite ingresar un mensaje de notificación para mostrar en el dispositivo durante un periodo corto

    !!! info

        Se recomiendan mensajes cortos
