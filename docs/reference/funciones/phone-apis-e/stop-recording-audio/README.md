# Stop Recording Audio

![](../../../../gitbook/assets/image%20%28543%29.png)

La función Stop Recording Audio permite al usuario parar la grabación del audio en el dispositivo

=== "Callbacks"

    ## On Finish Recording

    Se activa cuando se termina de grabar audio retornando el audio que se guardó durante el tiempo de grabación
