# Barcode Read

![](../../../../gitbook/assets/image%20%28506%29.png)

La función Barcode Read, permite al usuario hacer lectura de cualquier código de barras visible y legible

[Información general](https://docs.apphive.io/reference/funciones/informacion-general-de-las-funciones)



=== "Callbacks"

    ## On Barcode Read

    Se activa una vez se realiza la lectura de un código de barras retornando la información correspondiente al código
