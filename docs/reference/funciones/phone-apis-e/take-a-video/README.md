# Take a video

![](../../../../gitbook/assets/image%20%28555%29.png)

La función Take a video permite al usuario abrir la cámara para grabar videos 

!!! warning

    No abrirá la aplicación nativa de la cámara del teléfono

    Solo activará la cámara principal si es que el teléfono cuenta con mas cámaras


[Información general](https://docs.apphive.io/reference/funciones/informacion-general-de-las-funciones) 



=== "Callbacks"

    ## On Start Record

    Se activa cuando comienza la grabación del video.

    Terminado el proceso de grabar el video en la pantalla de grabación, retorna la dirección del video que fue grabado

    ## On Stop Record

    Se activa cuando se detiene el proceso de grabado de video
