# Vibration phone

![](../../../../gitbook/assets/image%20%28551%29.png)

La función Vibration phone permite al dispositivo activar el modo de vibración por un periodo de tiempo

!!! danger

    La vibración solo se activa en dispositivos con sistema operativo Android


[Información general](https://docs.apphive.io/reference/funciones/informacion-general-de-las-funciones) 



=== "Entry Vars"

    ## Time \(miliseconds & only android\)

    ![](../../../../gitbook/assets/image%20%28534%29.png)

    Permite asignar un tempo determinado en que el dispositivo se encontrará vibrando, este tiempo se estima en milisegundos
