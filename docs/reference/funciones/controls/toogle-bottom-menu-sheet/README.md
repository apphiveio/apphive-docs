# Toogle bottom menu sheet

![](../../../../gitbook/assets/image%20%28588%29.png)

La función Toogle bottom menu sheet permite al usuario abrir un menu inferior que se superpone a la pantalla principal

Esta función solo se activa cuando se activa la opción Bottom menu sheet

![](../../../../gitbook/assets/image%20%28634%29.png)

[Información general](https://docs.apphive.io/reference/funciones/informacion-general-de-las-funciones) 



=== "Callbacks"

    ## Error opening bottom menu sheet

    Se activa cuando ocurre un error durante el proceso de mostrar el bottom menu sheet

    ## Bottom menu sheet opened

    Se activa cuando se abre de forma satisfactoria el bottom menu sheet

=== "Entry Vars"

    ## Close

    ![](../../../../gitbook/assets/image%20%28635%29.png)

    Permite mostrar u ocultar el menu sheet, cuando se encuentra desactivado muestra el menú y cuando se activa oculta el menú
