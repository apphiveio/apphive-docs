# Trigger Event

![](../../../../gitbook/assets/image%20%28679%29.png)

La función Trigger Event permite reutilizar funciones que se encuentran dentro de un evento de un mismo control o distinto al que se llama esta función para volverse a ejecutar y realizar todo el proceso \(lógica de funciones\) dentro del evento del control seleccionado.

[Información general](https://docs.apphive.io/reference/funciones/informacion-general-de-las-funciones)



=== "Callbacks"

    ## Error

    Se activa cuando ocurre un error durante el proceso de ejecución de las funciones del evento del control seleccionado

    ## Success

    Se activa una vez que se comienzan a ejecutar las funciones del evento del control seleccionado

=== "Entry Vars"

    ## control

    ![](../../../../gitbook/assets/image%20%28684%29.png)

    Permite seleccionar uno de los controles que se encuentran dentro de la misma pantalla que se encuentra editando.

    ## Event name

    ![](../../../../gitbook/assets/image%20%28659%29.png)

    Una vez seleccionado el control, se muestran los eventos correspondientes al control; una vez seleccionado el evento, cuando se ejecute esta función se mandará a ejecución las funciones que se encuentren dentro del evento del control seleccionado.
