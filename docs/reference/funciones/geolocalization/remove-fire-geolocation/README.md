# Remove fire geolocation

![](../../../../gitbook/assets/image%20%28575%29.png)

La función Remove fire geolocation permite eliminar registros específicos de una grupo del Geo Fire

[Información general](https://docs.apphive.io/reference/funciones/informacion-general-de-las-funciones) 



=== "Callbacks"

    ## Error at remove location

    Se activa cuando sucede un error al tratar de eliminar el registro del grupo

    ## Success at remove location

    Se activa cuando se elimina el registro del grupo de forma exitosa

=== "Entry Vars"

    ## Group name

    ![](../../../../gitbook/assets/image%20%28574%29.png)

    Permite seleccionar el grupo de donde se eliminará el registro

    ## Key location

    ![](../../../../gitbook/assets/image%20%28572%29.png)

    Permite agregar el key del registro que se desea eliminar
